Web Components Era

This whole page is pure static HTML! No Hugo, no node.js. Just a single <script> tag allows you to use elements like <csrgo-header> natively.

Import via CDN:

<link rel="stylesheet" href="https://csrgo.github.io/csrgo-ui/dist/csrgo-ui.css">
<script src="https://csrgo.github.io/csrgo-ui/dist/csrgo-ui.js"></script>

Use in your HTML:

<csrgo-header brand-name="CSRGO"></csrgo-header>
<csrgo-footer></csrgo-footer>
